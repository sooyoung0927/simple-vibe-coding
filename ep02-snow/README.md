# ep02 눈 내리기

하얀 원 하나에서 시작해 자연스럽게 내리는 눈을 만든다. (영상 대본 메모)

- step01: 어두운 밤 하늘 위쪽에 하얀 원 하나(눈송이)를 그린다.
- step02: 눈송이가 일정한 속도로 아래로 떨어진다.
- step03: 바닥을 지나가면 다시 위에서 나타난다.
- step04: 눈송이를 150개로 늘려 화면에 흩뿌린다.
- step05: 눈송이마다 크기가 랜덤, 큰 눈송이일수록 빨리 떨어진다.
- step06: 바람에 흔들리듯 좌우로 살랑살랑 움직인다.
- step07: 투명도가 제각각이고 가장자리가 부드럽게 빛난다.
- step08: 마무리: 재등장 위치 랜덤, 옆으로 나간 눈 처리, 창 크기 대응. 완성!
