# ep03 공 튀기기

빨간 원 하나에서 시작해 진짜 고무공처럼 튀는 공을 만든다. (영상 대본 메모)

- step01: 어두운 배경 캔버스 위쪽에 빨간 원 하나(공)를 그린다.
- step02: 중력을 더해서 공이 점점 빨라지며 떨어진다.
- step03: 바닥을 그리고, 닿으면 속도가 줄어든 채로 튀어 오른다.
- step04: 튀는 높이가 아주 작아지면 멈춰서 바닥에 가만히 놓인다.
- step05: 바닥에 그림자를 깔아서, 공이 높을수록 작고 옅게 보이게 한다.
- step06: 부딪힐 때 납작하게 찌그러지고, 빠르게 움직일 땐 길쭉하게 늘어난다.
- step07: 공에 빛 받는 입체감(그라데이션)과 하이라이트를 입힌다.
- step08: 마무리: 클릭하면 던지기, 좌우 벽 튕김, 바닥 마찰, 굴러가는 줄무늬, 창 크기 대응.
