# ep04 아날로그 시계

베이지색 원 하나에서 시작해 진짜 벽시계처럼 째깍거리는 시계를 만든다. (영상 대본 메모)

- step01: 베이지색 둥근 시계 판(원) 하나를 어두운 배경 한가운데에 그린다.
- step02: 시계 판 둘레에 12개의 눈금을 돌려가며 그린다.
- step03: 현재 시각을 읽어서 시침·분침·초침 세 개를 그린다. (초침은 1초마다 뚝뚝 점프)
- step04: 밀리초까지 계산해서 세 바늘이 끊김 없이 부드럽게 흐르고, 시침도 분에 따라 조금씩 움직인다.
- step05: 초침을 다시 째깍 움직임으로 바꾸되, 튕기듯 살짝 지나쳤다가 돌아오는 이징을 준다.
- step06: 바늘 아래에 그림자를 깔아서 판 위에 떠 있는 느낌을 낸다.
- step07: 테두리에 금속 느낌 그라데이션을 넣고, 위쪽에 유리 반사를 얹어 입체감을 준다.
- step08: 마무리: 1~12 숫자, 60개 분 눈금, 가운데 캡, 초침 꼬리, 창 크기 대응을 더한다.
