# ep05 점프하는 슬라임

원 하나에서 시작해 진짜 젤리처럼 통통 튀는 슬라임을 만든다. (영상 대본 메모)

- step01: 원 하나(슬라임)를 바닥 위에 그린다.
- step02: 중력을 줘서 슬라임이 올라갔다 내려오며 통통 뛴다. (속도에 가속이 붙는다)
- step03: 바닥에 그림자를 깔고, 높이 뜰수록 작고 연하게 만든다.
- step04: 날 때는 세로로 길쭉, 착지할 때는 납작하게 찌그러졌다 돌아오는 눌림/늘어남을 준다.
- step05: 쉬는 시간, 점프 힘, 가로 방향을 무작위로 바꾸고 벽에서 튕기게 한다.
- step06: 눈을 달아서 움직이는 방향을 쳐다보게 한다.
- step07: 착지할 때 먼지 입자가 튀어 올랐다가 서서히 사라진다.
- step08: 마무리: 점프 전 웅크리기, 눈 깜빡임, 젤리 그라데이션·하이라이트, 창 크기 대응을 더한다.
