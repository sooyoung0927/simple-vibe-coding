# ep06 물결 파문

고리 하나에서 시작해 빗방울이 떨어지는 진짜 같은 물결 파문을 만든다. (영상 대본 메모)

- step01: 원 하나(파문의 고리)를 화면 가운데 그린다.
- step02: 고리가 프레임마다 조금씩 커져서 퍼져 나간다. (끝까지 퍼지면 다시 시작)
- step03: 퍼질수록 고리가 서서히 투명해진다. (페이드 아웃)
- step04: 화면을 클릭한 자리에서 파문이 생긴다. (여러 개를 동시에 관리)
- step05: 한 번 클릭에 고리 3개가 간격을 두고 따라 퍼진다. (진짜 물결은 겹겹이)
- step06: 고리가 처음엔 빠르게 퍼지다 점점 느려진다. (이징: 감속)
- step07: 빗방울이 무작위 위치·크기·속도·색으로 저절로 떨어진다.
- step08: 마무리: 물빛 배경, 원근감 있는 타원, 고리가 얇아지는 선, 중심 반짝임, 창 크기 대응.
