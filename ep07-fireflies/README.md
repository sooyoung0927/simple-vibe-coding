# ep07 반딧불이

원 하나에서 시작해 여름밤 풀숲의 반딧불이를 만든다. (영상 대본 메모)

- step01: 원 하나(반딧불이 몸)를 화면 가운데 그린다.
- step02: 원이 프레임마다 앞으로 움직인다. (화면 밖으로 나가면 반대쪽에서 나타남)
- step03: 방향이 조금씩 랜덤하게 틀어져서 흔들흔들 떠다닌다. (부드러운 방향 변화)
- step04: 원 둘레에 부드러운 빛번짐(글로우)을 더한다. (방사형 그라데이션)
- step05: 빛이 사인파로 부드럽게 깜빡인다. (밝아졌다 어두워졌다)
- step06: 반딧불이를 40마리로 늘린다. 크기·속도·색·깜빡이는 타이밍이 제각각.
- step07: 지나간 자리에 옅은 잔상(꼬리)이 남는다. (화면을 지우지 않고 어둡게 덮기)
- step08: 마무리: 밤하늘 배경과 풀숲 실루엣, 하얀 중심점, 숨쉬듯 깜빡임, 위아래 일렁임, 부드러운 방향 전환, 창 크기 대응.
